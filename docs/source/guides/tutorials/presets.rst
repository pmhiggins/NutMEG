Presets
=======

:any:`NutMEG.presets` are builders for key places and organisms that are of interest in astrobiology and geomicrobiology. In NutMEG v1 these were referred to as `saved_organisms` and  `saved_systems` but v2 has  a different structure.

Tutorials for presets are still under construction. Check back later for updates, and in the meantime the API documentation can get you started with some presets in development:

- :any:`Enceladus`: a `Reactor` that is preloaded with Enceladus-like geochemistry.
- :any:`KineticallyLimitedOrganism`: Creates a `BaseOrganism` using databases of pre-defined organism-specific kinetic and thermodynamic properties.
